# Creator Process: Sourcing to Delivery (Production Engine / UGC)

How we find a UGC creator, get them filming, and ship finished ads to the client.
Built from how Ivy Sprint 1 actually ran in ClickUp.

**Where it lives**
* Creators: Production Engine > Resources & Documents > [**Creator Database**](https://app.clickup.com/90121983842/v/li/901222423709) (one task per creator)
* Batches: Production Engine > [Client] > Sprint list (one task per batch, e.g. `B0036 - UGC - Harvest Holland`)
* New sprints start from **[15] Production Engine Template**
* Contracts: DocuSign. Raw footage: Google Drive. Edit review: Frame.io.

---

## Stage 1. Source (Ops)

1. Get the creator profile from the strategist's brief (e.g. "mom with kids", "with kids but no face").
2. Find creators on **Backstage, Instagram, X, LinkedIn** or our **Google Form**.
3. Add each one to the [Creator Database](https://app.clickup.com/90121983842/v/li/901222423709) as **new creator**. Fill in:
   * Client, Portfolio link, Creator Email, Source
   * Scope and Rate (see the offer below)
4. Write the **Scope** for this client. It feeds the outreach email.
5. Move the best fits to **shortlist**. This sends the outreach email automatically (Make.com). Keep good extras as **backup**.

## Stage 2. Outreach and offer (Ops)

1. Reach out and move to **in conversation**.
2. Send the offer in plain terms. Ivy example:
   * 2 short scripted videos (full brief provided) + 10 to 15 B-roll clips
   * Phone-filmed, natural. No studio, ring light or editing
   * Any product purchases needed are reimbursed
   * Perpetual usage rights for organic and paid on brand channels. No whitelisting unless agreed
   * **$200 for 2 scripts + B-roll**
3. Close it out:
   * Yes → next stage
   * Rate too high → **not interested - rate**
   * Ghosted → **no response**
   * Not a fit → **disqualified** (add a Note why)

## Stage 3. Contract and onboard (Ops)

1. Send the creator contract in DocuSign → **contract sent**.
2. Signed → **ready to onboard**.
3. Link the creator to their batch tasks (the **Creator** field on each batch).
4. Create a Drive folder for their raw footage and paste it in **Raw footage link** on the batch.
5. Creator starts work → **active**.

**Always have a backup.** If a locked creator goes quiet, swap in the next backup the same day.

## Stage 4. Brief (Strategist + CD)

Batch statuses in the sprint list:

1. **briefing**: strategist writes the brief (template fields: Track, Media Type, Motivator, Audience Insight, Product Benefit, Message Theme, Avatar, Why We're Testing, Winner link, What Stays). Paste it in **Brief Link**.
2. **brief review**: CD checks it. Notes → **brief feedback**, strategist fixes.
3. **send to creator**: Ops sends the approved brief and Drive folder to the creator.

## Stage 5. Film (Creator, Ops chases)

1. **recording**: creator is filming and uploads raw footage to the Drive folder.
2. Ops checks the footage is complete (all scripts + B-roll) and usable.
3. Creator stuck, silent or footage unusable → **production stuck**. Chase once, then swap to a backup.

## Stage 6. Edit (Editor + Strategist)

1. **ready to edit**: CD assigns the editor and tags them in a comment.
2. **editing**: editor has started.
3. **edit review**: editor pastes the Frame.io link. SLA: we review within 5 to 8 hours.
4. Strategist notes → **edit feedback**, editor revises.
5. **approved - prep files**: strategist approves. Editor drops finals in the Drive (a subfolder per batch, e.g. `B0036`).

## Stage 7. Deliver and close (Ops)

1. Ops puts final files in the client Drive and tracker within **30 to 60 minutes** of approval.
2. Files sent to the client → **launched**.
3. Send the creator the [invoice form](https://forms.clickup.com/90121983842/p/f/2kxv0nv2-872/16AFKVGXXRJAE8NAUU/form). They submit at least 1 day before the pay date.
4. We pay on the **15th and 30th**, via Wise or ACH. Finance marks it Paid and the creator gets a confirmation email.
5. Creator task → **paid - archived**.

## Quick status map

| Creator Database | Batch (sprint list) |
| --- | --- |
| new creator | not started |
| shortlist / backup | briefing |
| in conversation | brief review / brief feedback |
| contract sent | send to creator |
| ready to onboard | recording / production stuck |
| active | ready to edit → editing |
| paid - archived | edit review / edit feedback → approved - prep files → launched |

Off-ramps for creators: **disqualified**, **not interested - rate**, **no response**.

## Who owns what

* **Ops**: sourcing, offer, contract, footage folder, chasing, delivery, creator payment
* **Strategist**: briefs, edit approval
* **CD**: brief approval, assigns editor
* **Editor**: the cut, Frame.io link, final files
* **Creator**: films to brief, uploads raw footage on time
